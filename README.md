# Рывок и выдох — перетягивание каната в браузере

Дуэль на выносливость и ритм: против компьютера (3 уровня) или вдвоём на одном устройстве.

## Правила
- Рывок: **A** (с компьютером также пробел), второй игрок — **L**, на телефоне — кнопки «Тянуть».
- Каждый рывок тратит 9 единиц выносливости; сила рывка зависит от остатка.
- Выносливость восстанавливается сама, а после паузы 0,35 с — втрое быстрее. Нужно выбирать: давить или переждать.
- Такт: когда кольцо по центру светится зелёным, рывок в 1,8 раза сильнее и стоит на 4 единицы меньше.
- Не хватило сил на рывок — «выдохся»: 1 секунда без возможности тянуть.
- Победа: довести флаг до цветной линии на своей стороне. Матч длится 45 секунд; если время вышло, побеждает тот, к чьей стороне флаг ближе, у самого центра — ничья.
- Ввод до старта (обратный отсчёт) и после конца матча игнорируется. «Реванш» начинает матч с чистого состояния.
- Настройки и последние 8 результатов хранятся в localStorage.

## Как устроено
- `lib/game.ts` — вся логика (фазы, выносливость, ритм, ИИ, победа), без DOM и Three.js.
- `components/GameView.tsx` — Three.js-сцена (канат, флаг, команды), HUD и меню на Tailwind, ввод, звук (Web Audio).
- Инерция каната: рывок добавляет скорость, скорость затухает экспоненциально.

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # статический сайт в out/
```

## Публикация
Залить репозиторий на GitHub и импортировать в Vercel или Netlify (настройки по умолчанию). Подойдёт и любой статический хостинг: достаточно просто выложить содержимое `out/`.

## Использовано
Next.js, React, Three.js, Tailwind CSS, шрифт Unbounded (next/font). Шаблонов и чужих компонентов нет.
